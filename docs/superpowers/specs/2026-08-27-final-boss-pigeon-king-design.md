# 최종보스 "비둘킹" 설계 스펙

- 작성일: 2026-08-27
- 상태: 설계 확정, 구현 전
- 이전 브레인스토밍: 2026-07-20(퍼즐 유형 논의), 2026-08-26(pptx로 4패턴+손스케치 맵 확정)

## 1. 컨셉

첫 보스가 아니라 **최종보스**. 봄/여름/가을/겨울 4계절 패턴을 전부 사용하는 보스로, 4구역(봄/여름/가을/겨울 존)과 분리된 **별도 보스 전용 아레나**(5번째 공간, 구역 클리어 후 진입)에서 싸운다. 아레나 진입 시 문 잠김(도망 방지)은 이번 범위에서 **제외**.

보스 이름: 비둘킹.

## 2. 아레나 맵 (확정)

사용자 손스케치를 최종 맵으로 그대로 사용한다.

- 1층은 맵 전체 폭을 잇는 통바닥(끊김 없음) — 가을 패턴의 강풍 전진 구간에 낭떠러지 위험 없음.
- 그 위에 서로 다른 높이의 플랫폼 5개: 좌/우 중간 높이 2개, 중앙 상단 1개, 좌/우 끝 상단 2개.
- 각 플랫폼 하단에 고드름(겨울 패턴용, 평소엔 비활성/숨김 상태로 두고 겨울 페이즈 진입 시 활성화).
- 보스/플레이어 시작 위치: 맵 우측 끝 상단 플랫폼.
- 맵 양쪽 끝에 은행나무(가을 패턴용, `BossGinkgoTree`) 고정 배치. 평소엔 작은 크기로 있다가 가을 페이즈에서 자라나는 연출(추후 구현, 이번 스펙 범위에 포함해 기억해둘 것).

## 3. 페이즈 구조

- HP 100~75%: 기본 패턴만 사용.
- 75% / 50% / 25% / 10% 지점에서 각각 봄 → 여름 → 가을 → 겨울 순서로 계절 패턴이 **1회씩** 발동(반복 아님, 각 지점에서 한 번).
- 계절 패턴 진행 중(파훼 전)에는 보스가 **무적** + 기본 공격은 계속 시도(회피 압박 유지, 공격을 멈추지 않음).
- 파훼 성공 시: 필드 소멸 + 보스가 짧은 시간(2~3초) 무방비/피격 가능 상태가 된 뒤 무적 해제 → 기본 패턴 복귀.
- 이동: HP 50%까지는 보스가 제자리 고정. 50% 이하부터 `EnemyMovement`(Rigidbody 기반) 재사용해 플레이어 추적 이동 시작.

## 4. 기본 패턴

- 근접 공격 1~2종: `EnemyCombat` + `EnemyAttackHitbox` 그대로 재사용(사거리/쿨다운/선딜/히트박스 유지시간 구조 동일).
- 원거리 공격 1종(신규): 플레이어가 멀어졌을 때 발동하는 직선 투사체.

## 5. UI

화면 상단 보스 체력바(DOTween 연출). 단, 기존 `PlayerHealthUI`는 하트 개수 기반이라 보스에는 안 맞음 — 보스는 fillAmount 기반 게이지 바 신규 제작(계절 게이지 UI 패턴과 유사하게 DOTween `DOFillAmount` + Odin으로 Duration/Ease 정리).

## 6. 계절 패턴별 상세 설계

pptx 원문 + 손스케치 기준. 07-20에 검토했던 "기존 존 퍼즐 재활용형"은 채택하지 않고, pptx안 그대로 진행하기로 확정(2026-08-27).

### 6-1. 봄 — 꽃가루 돌진 [우산+성냥]

- 보스가 유저 방향으로 돌진하며 꽃가루를 살포한다.
- 유저는 우산으로 꽃가루 없는 플랫폼으로 이동해 피한다.
- 꽃가루가 충분히 퍼지면 성냥(TorchTool)으로 분진 폭발을 유도해 파훼한다.
- 필요 신규 요소: 돌진 이동 로직(보스), 꽃가루 살포/누적 필드, 분진 폭발 판정(`FlammableObject`의 인화성 확산 구조를 참고해 신규 컴포넌트로 구현).

### 6-2. 여름 — 비구름 [우산+선풍기+성냥] (3단계 순차 전환)

1. 우산으로 초반 약한 비를 방어.
2. 보스가 비구름을 유저 주변으로 뭉칠 때, 선풍기 반동으로 중심부에서 탈출.
3. 뭉친 먹구름을 성냥으로 강제 소멸시켜 파훼.

- **"당겨지는 힘"은 신규 메커니즘.** 기존 `WindZoneVolume`은 `windDirection` 기반으로 미는 힘만 지원(플레이어를 향해 당기는 인력은 없음). 보스 주변으로 플레이어를 끌어당기는 구역(가칭 `GravityWellVolume` 또는 `WindZoneVolume`에 인력 모드 추가)이 필요.

### 6-3. 가을 — 은행 뿌리기 [선풍기+성냥]

- 보스가 사라졌다가 맵 끝(유저 반대편) 은행나무 옆에 등장, 강풍과 함께 은행을 낙하시킨다.
- 우산은 강풍에 밀리므로 무력 — 선풍기 반동으로 전진해야 한다.
- 은행나무를 성냥으로 태워 보스에게 피해를 준다. `FlammableObject`를 상속/재사용 가능(기존 도화선 퍼즐 문앞 덩굴과 동일한 점화→연소 구조).
- 신규 클래스: `BossGinkgoTree`(기존 `GinkgoFruit`=은행 열매 낙하물과 이름 충돌 방지를 위해 완전 별도 클래스로 분리, 2026-08-27 확정).

### 6-4. 겨울 — 겨울나기 [성냥+고층 발판]

- 보스가 공중 이동하며 지상 공격, 고드름이 2/3층 플랫폼 하단에 생성(활성화)된다.
- 유저가 1층에서 성냥으로 온기존을 생성한다. **온기존 생성 위치는 5개 고드름 플랫폼 하단으로 제한**(2026-08-27 확정 — 플랫폼 사이 빈 지상에 만들면 보스가 고드름 없는 곳으로 유인되어 파훼가 막히는 문제 방지).
- 보스가 온기를 감지해 그 지점으로 이동 후 정지(정지 중엔 일반 타격 면역).
- 유저가 2/3층으로 점프해 보스 머리 위 고드름을 타격해 낙하시켜 피해를 준다.
- `EnemyMovement.cs`엔 온기 감지/특정 지점 유인 로직이 전혀 없어 AI 신규 구현 필요. 4패턴 중 제작비가 가장 크다.

## 7. 코드 재사용/신규 매핑 요약

| 요소 | 재사용 | 신규 |
|---|---|---|
| 근접 공격 | `EnemyCombat`, `EnemyAttackHitbox` | - |
| 원거리 공격 | - | 직선 투사체 컴포넌트 |
| 이동(50% 이하) | `EnemyMovement`(Rigidbody 기반) | - |
| 체력바 UI | DOTween 패턴(`PlayerHealthUI`의 이벤트 구독 구조 참고) | fillAmount 기반 신규 게이지 |
| 봄: 꽃가루/분진 폭발 | `FlammableObject`의 확산 구조 참고 | 꽃가루 살포/누적 필드 |
| 여름: 인력 | `WindZoneVolume` 구조 참고 | 당기는 힘(인력) 신규 |
| 가을: 은행나무 | `FlammableObject`(상속/재사용) | `BossGinkgoTree` |
| 겨울: 온기 감지 AI | - | 전량 신규(가장 큰 작업) |
| 플레이어 도구 사용 판정 | `ToolManager._activeTool`은 private | 보스 패턴이 "지금 어떤 도구를 쓰는 중인지" 읽을 public 판정 메서드 신규 추가 필요(예: `IsToolInUse<FanTool>()`) |

## 8. 남은 미정 사항

- 각 패턴의 정확한 수치(속도, 데미지, 지속시간, 판정 반경 등)는 구현 단계에서 Inspector 조절 가능하게 만들고 플레이테스트로 튜닝.
- 은행나무 "작았다가 자라나는" 연출의 트리거 타이밍(가을 페이즈 진입 시 vs 아레나 진입 시부터 서서히)은 미정.
